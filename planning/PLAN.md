# Assist — план проєкту

Assist — персональний вебпростір, де можна одночасно бачити план дня, ідеї, події, навчальні матеріали, файли й інструменти. Перша версія зосереджена на організації дня та Markdown-замітках. Вебінтерфейс працює з бекендом, який постійно доступний для синхронізації й нагадувань.

## Дошки й віджети

- Дошки — окремі робочі простори для різних цілей. Замітки прив’язані до дошок, і є загальний перегляд усіх заміток.
- Віджети вирівнюються по адаптивній сітці. Подвійний клік по заголовку згортає віджет до лівого краю. Біля краю з’являються нерухомі смужки із заголовками. Наведення показує попередній перегляд, клік відновлює віджет. Список можна прокручувати.
- Перемикач дошок з’являється біля нижнього краю. Клік вибирає дошку, а прокрутка одразу перемикає її. Для телефона й клавіатури потрібен доступ без наведення.
- Чистий інтерфейс із заокругленнями у стилі Apple, без капсульних елементів. Для дій передбачити систему клавіатурних команд, залишивши типові комбінації непризначеними.
- Сітка та анімації мають працювати плавно на різних екранах і враховувати системне налаштування зменшеного руху. CSS Grid — основа для першої версії. Yoga можна розглянути, якщо виникне потреба.

## Планування дня

- Завдання на весь день показуються зверху. Завдання без дати доступні в окремому списку.
- Інтервали часу відображаються смужками. Завдання, що накладаються, автоматично займають окремі доріжки. Час можна змінити перетягуванням або редагуванням.
- Точкове завдання або нагадування показується синьою лінією з кружечком. Після виконання воно стає зеленим, а на кружечку з’являється галочка.
- Таймлайн плавно стежить за поточним часом і тримає його біля середини віджета. Ручна прокрутка, перетягування або редагування призупиняє автоматичне стеження. Позначка поточного часу продовжує оновлюватися. Кнопка «Зараз» або перезавантаження повертає стеження.
- Час і дати відображаються в часовому поясі користувача. Окремо перевірити перехід між днями й літнім часом.

## Markdown і Obsidian

- Замітка відкривається зліва в панелі. Джерело даних — Markdown-файл, придатний для звичайного редагування.
- Системні вставки, зокрема блоки `assist`, дозволяють одному файлу містити кілька інтерактивних віджетів. Посилання на завдання відкриває його на потрібному дні таймлайну. Згодом воно може відкривати календар або командну дошку.
- Плагін Obsidian встановлюється вручну в першій версії. Він синхронізує одну вибрану папку сховища разом із вкладеними папками. Підключення відбувається за одноразовим кодом, прив’язаним до дошки.
- Синхронізація двостороння для створення, редагування, перейменування й видалення. Стабільний ідентифікатор зберігається у frontmatter. Нові файли потрапляють на дошку за замовчуванням. Після відновлення з’єднання зміни наздоганяються, а при конфлікті зберігаються обидві версії.

## Акаунти, Google Tasks і нагадування

- Основний вхід і відновлення доступу в першій версії — через Google. Кожен користувач має ізольований простір. Для розгортання потрібні HTTPS і шифрування сховища, а токени інтеграцій зберігаються в зашифрованому вигляді.
- Google Tasks підключається окремою згодою. Списки Google можна прив’язувати до дошок. Назва, дата й виконання синхронізуються в обидва боки. Локальне завдання можна додати до вибраного списку Google. Завдання Google Tasks також доступні в Google Calendar.
- API Google Tasks передає дату без часу доби. Початок, кінець і точний час залишаються в Assist, а дата синхронізується в часовому поясі користувача.
- Для завдань, прив’язаних до Google, нагадування веде Google. Час, заданий лише в Assist, сам по собі не запускає Google-сповіщення. Для інших завдань Assist надсилає Web Push після дозволу браузера, зокрема коли вкладка закрита. Бекенд переносить або скасовує нагадування після змін і повторює доставку після тимчасових помилок.

## Реалізація й перевірка

1. Зібрати вебінтерфейс на React і TypeScript та бекенд на Node.js, Fastify і PostgreSQL. Окремо передбачити фонову обробку нагадувань у постійно запущеному застосунку.
2. Реалізувати дошки, сітку віджетів, таймлайн і Markdown-замітки. Відкрити базові інтерфейси та реєстр для підключення нових віджетів.
3. Підключити Google OAuth, Google Tasks, Web Push і синхронізацію Obsidian. Для розгортання потрібні постійний хост, Docker Compose, HTTPS, Google OAuth і VAPID.
4. Перевірити потоки на телефоні й комп’ютері, клавіатуру й дотик, накладання інтервалів, дати й часові пояси, ізоляцію користувачів і збереження даних після перезапуску. На живих інтеграціях перевірити двосторонню синхронізацію Google Tasks без дублікатів, Web Push із закритою вкладкою та відновлення Obsidian після офлайн-змін, перейменувань і конфліктів.

## Подальший розвиток

- Ручний конструктор віджетів із кількома рівнями складності, довільним виглядом і можливістю взаємодії між віджетами.
- Ширший календар, ідеї, події, навчання, файли й інші інструменти. Вільне розміщення смужок таймлайну як варіант розвитку.
- Командні дошки, планування для команд, корпоративні акаунти та права доступу.
- Інші способи входу, додатковий ключ або другий фактор і сценарії відновлення.
- Підключення LLM через CLI або токен.
